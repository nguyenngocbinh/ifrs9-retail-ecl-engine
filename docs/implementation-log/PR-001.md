## Recorded choices

- Upstream sources provide PD/LGD/EAD, pool, and Stage/SICR.
- Scenario PDs (Downturn/Base/Upturn) already exist upstream; do not calculate them from `PD FWL ± 1 SE`.
- Scenario weights currently recorded as 15.68% / 68.64% / 15.68%; authoritative source still needs to be identified.
- PD semantics: annual unconditional marginal PD on original cohort.
- Stage 1 -> 12-month ECL; Stage 2 -> lifetime ECL; Stage 3 -> `ECL_DEFAULT` with current PD=1 rule, subject to curve semantics approval.
- LGD and EAD are assumed flat across scenarios for the initial scope.
- EIR currently described as a common curve across pools, with one rate per period.
- POCI excluded from initial scope.
- Output requires account-level records and aggregation by pool/product/portfolio.
- Run IDs, source versioning, audit log, deterministic rerun, reconciliation, and atomic publication are production requirements.

## Important blockers

1. EAD/LGD curve semantics and Stage 3 loss allocation are unresolved.
2. Discount factor `DF(t)=1/(1+EIR(t))^t` requires reconciliation with approved policy if EIR varies by period.
3. Physical source tables, keys, grains, scenario-weight source, EIR source, lifetime horizon, and POCI exclusion mechanism are not yet confirmed.
