# PR #45 — Shared EAD curve loader

## Summary

- Add `ecl_stg.EADCurveInput` as a normalized annual EAD intake contract for all retail products.
- Add `ecl_core.usp_LoadEADCurve @RUN_ID` to validate and promote input rows to canonical `ecl_stg.EADCurve` atomically.
- Add synthetic SQL Server 2022 regression coverage for Auto and Non-Revolving Personal Loan rows, period coverage, and repeat-load behavior.
- Add migration 006 and include it in the SQL Server 2022 CI migration/test sequence.

## Design

Product-specific ETL transforms its source into one row per `RUN_ID + ACCOUNT_ID + FORECAST_PERIOD`. The shared procedure does not calculate amortization, infer source balance semantics, or consume monthly schedules directly. It validates that the run exists and is pre-calculation, the process date matches, EAD is non-negative and in VND, and every active account has active EAD coverage for every annual period through maturity (maximum 120 periods).

The procedure replaces only the canonical EAD rows for the supplied run. The normalized input rows remain available for audit/replay. The ECL calculation procedure is unchanged.
