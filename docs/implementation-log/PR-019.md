# PR-019 — Add GitHub Actions SQL integration tests

## Goal

Run the repository's schema migrations and synthetic lifecycle smoke test automatically on pull requests and pushes to `main`.

## Included

- `.github/workflows/sql-server-tests.yml`: provisions a disposable SQL Server container, installs `sqlcmd`, applies migrations in order, and runs the transactional smoke test.
- CI fails on SQL errors through `sqlcmd -b`.
- Workflow can also be started manually with `workflow_dispatch`.

## Validation scope and limitations

- CI uses the SQL Server 2017 Linux container because it is available for hosted GitHub Actions; this is a useful integration check but is **not** proof of execution on SQL Server 2016.
- No production/source database is accessed. All test records are synthetic and the smoke test rolls back its transaction.
- No customer data, credentials, or ECL calculation formulas are introduced.
- The workflow has not been executed in this authoring session. Its first run will validate the service image, client installation, migration deployment, and smoke test end-to-end.
- The workflow uses a CI-only SA password; it is not a repository secret and must never be reused outside disposable CI.
