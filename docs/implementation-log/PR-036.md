# PR #23 — Input data-quality gates

**Date:** 2026-10-16  
**Status:** Awaiting SQL Server 2022 CI and review.

## Changes
- Add fatal reporting-date consistency checks across ACCOUNT, PD, LGD, EAD, EIR and selected SCENARIO_WEIGHT inputs.
- Add synthetic regression coverage for a wrong-date account row and duplicate ACCOUNT/PD logical grains.
- Wire the regression into SQL Server 2022 CI and update the roadmap.

## Assertions
- A staged account row whose PROCESS_DATE differs from its run's reporting date creates a fatal INPUT_PROCESS_DATE_MISMATCH finding.
- Duplicate account and PD logical grains are rejected by their canonical primary keys, including an attempted duplicate PD row with a different reporting date.
- No ECL output rows are produced.

## Scope boundary
This PR adds structural pre-calculation controls only. It does not add ECL formulas, calculate outputs, or claim result-level rerun idempotency or publication atomicity.
