## Assertions
- A newer \`RECONCILIATION = FAILED\` event takes precedence over an earlier success and blocks transition to \`SUCCEEDED\` (error 51036).
- A publication milestone cannot be recorded before the run reaches \`SUCCEEDED\` (error 51045).
- A \`PUBLICATION = FAILED\` event blocks transition to \`PUBLISHED\` (error 51037).
- Rejected transitions leave run status unchanged and the synthetic runs have no ECL output rows.

## Scope boundary
The repository has no calculation/output publication procedure yet. This test validates lifecycle gates and rejection behavior; it does **not** prove transactional atomicity of a future output writer. True partial-write rollback testing remains required when that procedure exists. The test commits synthetic fixtures in the isolated CI database so rejected transitions can be checked against persisted status.
