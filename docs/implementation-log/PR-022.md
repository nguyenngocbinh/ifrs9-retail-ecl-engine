# PR-022 — Canonical input contract baseline

## Scope
- Documents logical grain, units, period semantics, row-count definition and run-wide invariants for the six input families.
- Records the confirmed 12-month FTP EIR input and the agreed fractional final-period rule without changing the discount formula.
- Records Stage 3 upstream EAD/LGD certification as a required evidence gate.
- Defines scenario-weight version provenance/history requirements and explicitly prohibits in-place changes to historical versions.
- Keeps final ECL formulas blocked pending source-owner, Treasury and scenario-weight provenance evidence.
- POCI is out of scope for this contract and is not part of its input requirements or calculation gates.

## Guardrails
- No source-system survey, production database access, customer data, or credentials.
- No ECL formulas or changes to calculation behavior.
- The logical contract is not evidence that upstream mapping or rate semantics have been certified.
- SQL Server 2016 compatibility remains unverified; current CI targets SQL Server 2017.

## Review checklist
- [ ] Upstream owners confirm source-to-column mappings and snapshot count definition.
- [ ] Treasury confirms FTP 12-month rate numeric units and approved use in the selected formula.
- [ ] Scenario-weight source and approval references are populated and retained by version.
- [ ] Upstream owners certify Stage 3 EAD/LGD semantics.
