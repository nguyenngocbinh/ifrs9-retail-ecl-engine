# PR-025 — Remove mandatory scenario-weight approval gate

## User decision

The engine should calculate using the data supplied to it. Do not require business approval workflow metadata as a precondition to ECL input validation.

## Changes

- Remove the proposed migration that added source/approval/approver/timestamp/change-reason fields to `ecl_cfg.ScenarioWeightVersion`.
- Remove the synthetic test whose expected outcome was failure solely because approval/provenance fields were absent.
- Keep CI deploying migrations 001–004 and running the existing input-contract regression suite; do not deploy migration 005.
- Update the roadmap to clarify that scenario weights are supplied configuration data, with technical checks for effective dates and valid Downturn/Base/Upturn weights summing to 100%.

## Validation boundaries

- Technical checks for missing/invalid weights, effectivity, and total weight remain.
- No approval metadata is required.
- No ECL formulas or publication behavior are introduced.
- No production data or credentials are used.
- SQL Server 2017 CI does not prove SQL Server 2016 compatibility.
