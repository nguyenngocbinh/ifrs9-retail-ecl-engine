# PR-025 — Scenario-weight provenance gate

## Scope
- Add source, source-reference, approval-reference, approver, approval timestamp and change-reason fields to scenario-weight version metadata.
- Update input validation so a selected weight version missing any required provenance field emits fatal finding `SCENARIO_WEIGHT_PROVENANCE_MISSING`.
- Add a synthetic regression test proving the gate blocks validation and does not create ECL detail.
- Wire migration 005 and its test into the SQL Server integration workflow.
- Refresh roadmap after PR #24 merged.

## Guardrails
- No ECL formulas or publication behavior.
- Synthetic data only; regression transaction rolls back.
- No source-system survey, production data, or credentials.
- This gate checks that evidence references are populated; it does not verify that the referenced approval is genuine or sufficient.
- Existing historical scenario-weight versions are not auto-populated or approved. Responsible owners must provide correct provenance.
- SQL Server 2017 CI is not proof of SQL Server 2016 compatibility.

## Acceptance checklist
- [x] Version metadata has explicit provenance fields.
- [x] Missing provenance produces a fatal validation finding.
- [x] Regression test asserts no ECL detail is generated.
- [ ] CI passes on the PR branch.
- [ ] Actual source/approval evidence is supplied by owners.
- [ ] SQL Server 2016 verification remains outstanding.
