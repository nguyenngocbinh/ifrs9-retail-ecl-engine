# PR-038 — Complete input data-quality regression coverage

## Purpose
Extend the synthetic-only regression test for canonical input data quality and run the complete SQL Server 2022 CI suite in the same branch/PR.

## Changes

- Asserts that each of the six families emits a fatal `INPUT_PROCESS_DATE_MISMATCH` finding for the deliberately wrong-date row.
- Asserts no ECL detail, account-level or portfolio-summary output is produced.
- Updated `TODO.md` and this implementation log. Existing SQL Server 2022 workflow already includes this test, so the PR path trigger runs the full suite.
