# PR #41 — Add ECL calculation fault-injection rollback regression

## Scope
- Add a synthetic SQL Server regression that injects a failure during the account-output write, after detail rows have been inserted.
- Assert that the calculation procedure rolls back detail/account/portfolio outputs atomically.
- Assert that the run remains in CALCULATING and no successful calculation/reconciliation milestone is persisted.
- Add the test to the SQL Server 2022 CI sequence.

## Safety / scope
- Uses only synthetic account identifiers and synthetic input curves.
- The test-only trigger is scoped to the SYN-ROLLBACK-% fixture prefix and is removed after the assertion or during error cleanup.
- Test fixture rows are committed before invoking the procedure so the test can inspect the run after the procedure rolls back its own transaction; all fixture rows are deleted after the assertions.
- No production procedure, schema, or methodology is changed.
