# PR-016 — Run control, snapshots, and audit design

## Goal
Define a safe run lifecycle and reproducibility contract after the logical schema foundation.

## Scope
- Document allowed run-state transitions and terminal states.
- Define full versus selective run scope.
- Define validation and publication gates.
- Define snapshot/version immutability and identify the missing run-to-input-version manifest.
- Specify concurrency, idempotency, audit, cancellation, and recovery requirements.
- Update the repository roadmap.

## Validation performed
- Cross-checked lifecycle states against `ecl_core.RunControl.RUN_STATUS` in the logical schema proposal.
- Identified a schema gap: an explicit run-to-input-version manifest is needed before ingestion/calculation can be reproducible.
- Confirmed publication must be separate from successful calculation and must be blocked by failed validation or reconciliation.
