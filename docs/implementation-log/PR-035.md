## Assertions
- A selective run whose active account matches both requested product and pool passes the scope check.
- Product and pool mismatches are separately recorded as fatal \`RUN_SCOPE_MISMATCH\` findings.
- Scope findings block the transition from \`VALIDATING\` to \`CALCULATING\` (error 51035); rejected transition leaves status unchanged.
- No ECL output rows are produced.

## Scope boundary
This test exercises the existing input validator and lifecycle gate using synthetic canonical-table data. It does not implement ECL formulas or claim that a calculation procedure exists. The test transaction is rolled back.
