# PR #002 — Source inventory toolkit

- Branch: docs/pr-002-source-inventory-kit
- Scope: source discovery templates and metadata collection utilities
- Status: prepared for review; physical source inventory remains pending source-system metadata
- Engine target: SQL Server 2016 / T-SQL

## Objectives

- Provide a safe, repeatable method to inventory actual source objects.
- Collect catalog metadata without extracting customer-level business data.
- Define templates for physical data dictionary, source grain/keys, and lineage.
- Preserve the rule that physical mappings must be evidence-based.

- docs/source-inventory/README.md

## Validation performed

- Reviewed the SQL script for SQL Server 2016-compatible catalog views and syntax.
- The script reads sys.objects, sys.schemas, sys.columns, sys.tables, sys.indexes, sys.index_columns, sys.foreign_keys, sys.foreign_key_columns, and sys.synonyms.
- The script does not query customer/business data rows.
- The script has not been executed against the user's database because no database connection or DDL was provided.
- No source table names, keys, data types, or grains are asserted as facts.
