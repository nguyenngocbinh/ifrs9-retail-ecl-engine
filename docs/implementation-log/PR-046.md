# PR #46 — Standardize EAD objects on Non-Revolving naming

## Goal
Replace Auto-specific object names with Non-Revolving EAD names so the implementation can be extended beyond Auto without renaming the objects again.

## Naming
- DB2 table: `RM_RDM_MOP_PROD.TBL_NONREVOLVING_EAD_SCHEDULE`
- DB2 procedure: `RM_RDM_MOP_PROD.SP_CALC_NONREVOLVING_EAD`
- SQL Server source staging target for follow-up implementation: `ecl_stg.NonRevolvingEADSource`
- SQL Server curve-building procedure for follow-up implementation: `ecl_core.usp_BuildNonRevolvingEADCurve`
- Canonical ECL input remains `ecl_stg.EADCurve`; shared validation remains `ecl_core.usp_LoadEADCurve`.

## Scope
- Add renamed DB2 install scripts and update DB2 documentation.
- Add manual migration guidance for existing Auto-named DB2 objects.
- Do not change the canonical EAD curve schema or `ecl_core.usp_CalculateECL`.

## Important limitation
The new DB2 procedure retains the existing source tables and first-pass calculation assumptions. Renaming the objects does not establish that every Non-Revolving product shares Auto's source semantics. Confirm product scope and schedule semantics before production use. SQL Server staging and annual curve-building are follow-up implementation work; no DB2-to-SQL Server ETL is included here.

## Validation
- Static review only; no live DB2 execution has been performed.
