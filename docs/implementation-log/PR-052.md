# PR #68 — Load shared EIR from FTP 12-month source

## Purpose

Add source ETL and shared validation for the canonical shared EIR curve from `CORE.dbo.rb_ftp_bv_12m`.

## Changes

- `database/009_eir_ftp_bv_source_loader.sql`
  - Allows `RATE_BASIS='FTP_12M'` in the canonical EIR table.
  - Adds `ecl_core.usp_StageSourceEIRCurve` to load VND FTP rates into `ecl_stg.EIRCurve` at the shared `RUN_ID + FORECAST_PERIOD` grain.
  - Adds `ecl_core.usp_LoadEIRCurve` to validate curve coverage, reporting date, rate range, rate basis and audit the validated load.
- `tests/sql/eir_curve_loader_tests.sql`: synthetic source fixture and regression assertions.
- `.github/workflows/sql-server-2022-tests.yml`: runs the new migration and test.
- `docs/canonical-input-contract.md`, `docs/implementation-runbook.vi.md`, `README.vi.md`, and `TODO.md`: document mapping, invocation and remaining source-semantic check.

## Mapping contract

- `FORECAST_PERIOD = N` maps to `DATEADD(month, 12*N, RunControl.PROCESS_DATE)`.
- Select the most recent VND `process_date` on or before the run's `PROCESS_DATE` and apply that rate to every forecast period. Never select source observations dated after the run date; that would introduce look-ahead bias.
- `ftp_bv` is copied as supplied; no division by 100 is applied. This follows the current canonical contract but must be confirmed with the source data owner before operational use because an input value of 9.2 materially changes the discount factor.
- If `CORE` is on a separate SQL Server instance, use an approved same-instance view/linked-server abstraction and configure the source parameters accordingly.

## Validation

- Added a test that checks annual horizon expansion, selected currency, source value preservation and EIR load audit.
- SQL Server 2022 CI must pass before merging.
- The source table's business meaning/unit and the instance-level source-access arrangement remain deployment checks.

## Safety

This PR is intended for a feature branch and must not be merged into `main` without explicit approval.
